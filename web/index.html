這些資料在哪？
開啟 VPS 服務商控制台，找到你的伺服器的“遠端連線”或“登入資料”。將公網 IP、遠端用戶名和該帳戶當前的密碼填入登入頁。
這裏需要伺服器登入密碼，不是服務商網站的帳戶密碼，也不是 Safe Code 的工作用戶密碼。修改過 root 密碼後，請使用新密碼；部分控制台不會同步顯示手動修改後的密碼。


更新登入密碼
在 VPS 控制台或 SSH 中修改了 root 等登入帳戶的密碼？在這裏驗證新密碼並恢復連線。此操作不會修改伺服器密碼，原掛載和待上載快取會保留。
恢復後，如遠端桌面或網頁連線已斷開，請重新開啟。


進階連線
通常為 22；服務商修改過連接埠時再調整。直接進入可在不連接伺服器的情況下預覽介面。
