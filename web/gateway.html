      前置審查

      開啟後，網關在轉發前審查本輪用戶文字。此設定對所有 API Key 生效。

      當前網關需要先完成 CloudCLI 網頁授權才能使用內置模型。

      API 排隊

      同一時間只讓一把 Key 使用網關。該 Key 的請求全部結束後，連續空閒 60 秒才輪到下一把 Key。

      處理槽位

      預設 0，表示網關不設處理槽位上限。設定正整數時，所有密鑰共享槽位，調低上限不會中斷正在處理的請求。

      更新舊 Key

      網關地址、連接埠或證書變更後，貼上原 Key 以更新接入地址。原有用量和額度會繼續保留。

      建立密鑰

      「Default」「Best」等自動選項由 CloudCLI 決定實際使用的模型。

      請先在 Safe Code 的「網關設定」升級 VPS 網關，以設定模型權限和失效時間。

      關注主播
      建立更多密鑰需要啟用碼，關注主播可以獲得啟用碼。

      密鑰已建立

      完整密鑰僅在這裏顯示。請複製後回到 Safe Code 主介面的「API Key 接入」貼上。
