# 检查更新

在「更新与反馈」中可以手动检查。Beta 客户端会查询官方预发布和正式版，正式客户端只查询正式发行版。客户端使用缓存减少重复请求，收到 GitHub API 的 403 或 429 时改用官方发布页或订阅。你也可以手动下载 [GitHub Releases](https://github.com/Muchuaner/safe-code/releases) 中对应平台的安装包。

应用内更新要求安装包名称和平台匹配，下载地址属于本仓库的 Release。客户端检查文件大小和 SHA-256，安装前会再次校验。通过备用来源发现新版时，客户端提供 GitHub 发布页链接，可在发布页查看校验文件。

点击安装后，客户端会先检查运行任务和挂载状态，再打开安装入口。检查更新独立于使用统计和匿名诊断开关。[匿名功能诊断](DIAGNOSTICS.md)
