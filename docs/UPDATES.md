# 檢查更新

在「更新與回饋」中可以手動檢查。Beta 客戶端會查詢官方預發佈和正式版，正式客戶端只查詢正式發行版。客戶端使用快取減少重複請求，收到 GitHub API 的 403 或 429 時改用官方發佈頁或訂閱。你也可以手動下載 [GitHub Releases](https://github.com/Muchuaner/safe-code/releases) 中對應平台的安裝包。

應用內更新要求安裝包名稱和平台匹配，下載地址屬於本倉庫的 Release。客戶端檢查檔案大小和 SHA-256，安裝前會再次校驗。透過備用來源發現新版時，客戶端提供 GitHub 發佈頁連結，可在發佈頁查看校驗檔案。

點擊安裝後，客戶端會先檢查執行任務和掛載狀態，再開啟安裝入口。檢查更新獨立於使用統計和匿名診斷開關。[匿名功能診斷](DIAGNOSTICS.md)
