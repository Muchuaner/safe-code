# Safe Code Beta-0.4.3.4

本次合并此前完整功能更新，通过 GitHub 预发布渠道分发。

- 目录挂载支持超过 2 GB 的流式传输、范围读取、断线重连和安全退出；新增服务器空目录创建与底部状态入口。
- 挂载目录自动登记到 CloudCLI 项目列表，卸载后归档自动项目，重挂恢复，保留项目会话、名称和收藏。
- 托盘面板缩至 252 DIP，发送、接收、读写三列，操作按钮横排。
- 新增“本机远程控制”：明确权限确认后部署专用 SSH 服务与反向通道，支持复制连接命令和停用撤权。默认关闭，仅监听回环地址；启用后服务器端 AI 能以当前 Windows 账户权限操作本机。
- 新增“Codex 接入 Claude”实验模块，位于 SSH 后，保留作者致谢占位和原有许可。需用户主动同意运行第三方组件；默认关闭、项目只读，不自动修改或切换 Codex/CC Switch 配置。
- 改善安装准备、APT 状态码 100 的具体原因提示、官方 Claude Code 文件校验上传、CloudCLI 技术引导，以及诊断问题编号和反馈关联。

Windows 10 2004 / Windows 11 x64。推荐下载 Setup-x64.exe，包含 WebView2 离线运行时；win-x64.zip 为自包含便携包。完整包包含未修改的 Claude Code Linux x64 2.1.311、Microsoft OpenSSH 和可选第三方适配器，许可与来源校验记录随包保留。

验证范围：本地界面和核心回归、诊断接收端、服务更新及哈希拒绝测试、超过 2 GB 的双向内容校验与中断保护；之前已完成 214 与 Ubuntu 测试虚拟机上的真实挂载、CloudCLI 项目联动、本机 SSH 登录、临时文件读写和停用撤权。本机控制最终保持关闭。

实验适配器已完成静态审查、安装/撤销隔离夹具和界面检查。按用户选择，本次未运行未签名第三方 EXE、未部署真实适配服务、未发送 Claude 模型请求；不宣称 Codex 桌面完整兼容性已通过。使用前需自行准备 Claude 授权并理解数据发送范围和额度消耗。
