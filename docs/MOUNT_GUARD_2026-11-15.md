# 大文件挂载、空目录选择与托盘守护

用户反馈大文件挂载或传输卡住、断线后不恢复，服务器目录选择器也不能直接新建空目录。本次同时完善文件桥、挂载连接生命周期和界面，未覆盖用户现有目录或修改其项目文件。

## 最终行为

服务器目录选择器新增“新建空白文件夹”。用户在当前工作用户目录内输入名称后创建空目录，并直接选中填入挂载目标。创建以普通工作用户运行，同名项不覆盖，路径越界与符号链接逃逸拒绝，等待有超时且不会遗留继续执行的子进程；创建时锁定重复提交与关闭动作。原来拒绝将非空目录作为新挂载点的保护保留。

原文件桥对上传内容的 2 GiB 硬限制已移除，改为 64 位长度及分块流式读写，保护上限为单次 1 TiB。支持 HTTP 字节范围与 If-Range 条件读取，按每个文件独立串行写入，不阻塞其他文件上传。120 秒空闲超时只针对没有数据进展的连接，不是整次大文件传输的总时限。上传成功才原子替换目标；中断、超时或写入失败不覆盖原文件，也不会把第二个 HTTP 错误响应混入已经开始传输的文件内容。

挂载使用独立 SSH 连接，带原主机密钥核对。重连沿用原远端回环端口、会话密码和本机文件桥，保留 FUSE 挂载及待上传缓存；读取 mountinfo 检测挂载，不访问可能等待网络的 FUSE 路径做健康检查。服务器挂载缺失时只恢复缺失项，正常目录不重挂。主控制连接也有健康检查和恢复。清理转发时对 SSH 库的停止异常做隔离，确保仍会关闭旧 SSH 会话，避免旧监听阻塞恢复。服务器身份变化时暂停自动连接，不自动信任新密钥。

增加右下角品牌托盘图标、白底绿色状态面板和主界面底部入口。面板显示目录数、单调时钟计算的持续时长、双向文件内容字节、完成的完整文件读写次数和当前传输数，支持显示主界面、立即重连、退出并安全卸载。目录扫描不计为文件传输；字节含中断和重试已传出的内容，重复完整文件操作分别计数。统计只在本机显示，不扫描全部文件计算总数，不上传统计、目录或文件内容。

最小化进入托盘；有挂载或正在部署时关闭主界面也转入后台。明确退出会先同步卸载，不能确认完成时保留保护并提示，不直接断开文件桥。保护依赖客户端仍在运行，不承诺强制结束进程或关机后继续传输。

## 缓存与边界

davfs2 配置更新为 1 GiB 常规缓存、120 秒读取超时及较短网络重试间隔，并提高失败上传重试上限。缓存上限不是大文件大小上限：davfs2 会缓存完整的打开文件，因此 VPS 仍需有足够磁盘空间。没有将增加 cache_size 当作修复原 2 GiB 限制的替代方案。参考 [Ubuntu davfs2.conf 手册](https://manpages.ubuntu.com/manpages/noble/man5/davfs2.conf.5.html)。

中断 PUT 会从服务端保留的文件缓存重试上传，不宣称支持按字节续传 PUT。HTTP Range 支持用于读取，不能据此宣称所有应用都会使用分段下载。两端并发编辑同一文件仍应由用户协调，未增加冲突合并机制。

- 文件桥以真实 `2 GiB + 65537` 字节内容完成上传、下载与 SHA256 校验；验证超过 2 GiB 的范围读取、后缀范围、非法范围拒绝、并行文件写入、传输中断保留原文件、空闲超时和真实字节统计，托管内存增量小于 256 MiB。
- 21 项 Python 检查通过，包含空目录创建、重名和越界保护、现有挂载及已有账号初始化等回归；目录创建自动选中、重复提交防护、挂载保存进度及诊断同意界面检查通过。
- SSH/SFTP 挂载生命周期夹具检查通过：无效新目标不会关闭旧通道或覆盖原保存设置，多次重挂保留客户端标识，空映射安全卸载。
- 214 虚拟机使用独立随机测试目录、独立客户端标识验证两组挂载。确认实际传输已有文件字节后关闭专用 SSH 底层 socket，8 MiB 文件重试恢复后 SHA256 完全一致，正常挂载 ID 保持不变。单独卸载第二组测试挂载后仅第二组恢复，第一组挂载 ID 未改变；再断开控制连接，控制连接自动恢复且不影响现有挂载。最后安全卸载，测试目录清理。
- 对一次中断的测试程序，恢复原回环会话后，遗留的测试缓存成功回传并通过 SHA256 校验，再正常卸载；未通过强制卸载或删除待上传缓存掩盖失败。
- Windows 客户端编译通过，0 警告、0 错误。Windows App 中实机预览托盘图标和面板，绿色、字体、边距与现有界面一致；预览使用明确标注的示例计数，不作为真实传输统计。临时预览计划任务完成后删除，未停止用户原客户端。
