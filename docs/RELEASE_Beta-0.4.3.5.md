# Safe Code Beta-0.4.3.5

本次为 Windows 修复更新，通过 GitHub 预发布渠道分发。

- 新增“更新登录密码”：服务器侧修改 root 等登录账户密码后，可验证新密码并恢复原连接和挂载，避免旧凭据导致重连、卸载和退出受阻。恢复保留原文件桥、挂载标识与待上传缓存；认证失败暂停自动重试，普通网络故障仍重试。
- 登录页新增“这些信息在哪？”图解教程，使用示例 IP，说明服务器登录密码与工作用户密码的区别；优化输入框间距、辅助按钮对齐和底部留白。
- 加强两个“自定义”按钮的轮廓。工作账户首次保存不提醒，第二次起或已有完成的工作账户时，弹出修改提醒；取消不保存，确认则立即应用。
- “Codex 接入 Claude”移至维护页最后，特别鸣谢：亚撒西の空白。模块与设置弹窗明确提示“非本人创作，未经本人测试。使用请自行承担后果”，启用前需同意风险说明。

推荐下载 `SafeCode-Beta-0.4.3.5-Setup-x64.exe`，支持 Windows 10 2004 / Windows 11 x64，包含 .NET 和 WebView2 离线依赖；`win-x64.zip` 为便携包。继续保留上一版完整功能、官方 Claude Code Linux x64 2.1.311、Microsoft OpenSSH 及可选第三方适配器和原有许可。macOS 仍为仓库中的独立开发版，本次发布附件为 Windows x64。

服务器改密后，已有 SSH 会话可能暂时可用，但新连接会因旧密码失败。请使用服务器卡片中的“更新登录密码”输入当前登录账户的新密码；如果服务器禁止密码登录、账户被锁定或主机密钥变化，仍需通过 VPS 控制台核查。恢复后，如远程桌面或网页通道已断开，请重新打开。

验证覆盖本地真实 SSH/SFTP 协议中的密码切换、错误密码与恢复准备失败保护、原文件桥和端口保持、恢复后安全卸载、主机身份变化拒绝；以及登录教程、账户确认、挂载界面和更新/诊断回归。改密恢复远端使用隔离协议夹具，不将其表述为本轮粉丝 VPS 或真实 Linux FUSE 内容恢复验收。未运行第三方适配器 EXE，未发送 Claude 模型请求。
