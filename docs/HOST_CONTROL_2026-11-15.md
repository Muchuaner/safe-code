# 本机远程控制

用户此前在《修复维护界面布局问题》（01a1da99-bb6e-7771-b380-55c42a7017ef）提出 OpenSSH / 端口映射 / 给 AI 的连接命令，当时要求等待虚拟开发环境完成。本次将它作为维护页“目录挂载”下方的独立模块实现，默认关闭。

## 使用流程和权限

在“本机远程控制”点“设置”，阅读风险说明，填写别名，勾选同意后点“同意并开始部署”，完成 Windows UAC 管理员确认。当前要求 Windows x64，且当前登录账户自身具有管理员权限；使用另一个管理员身份代为授权不支持。此版本不提供 macOS 客户端。

AI 获得 SSH 登录账户的命令行权限，可读取、修改、删除该账户可访问的文件并运行程序；管理员账户可能以管理员权限执行。停用只能关闭控制通道，不撤销已经执行的操作。软件保持运行时维持通道，断线后核对原服务器指纹并重连；服务器身份变化时停止自动重连。退出 Safe Code 前关闭通道；异常结束后，本机专用 SSH 进程在心跳过期后结束，不承诺撤销 AI 另行创建的持久任务。

实际完成服务器到本机的公钥 SSH `whoami` 验证，并核对真实 Windows 账户 SID 与本机授权账户完全匹配后，才显示可复制命令。命令形式为 `ssh -F /home/<工作用户>/.ssh/safe-code-host/<标识>/config <别名>`。独立配置保留别名的同时避免改写用户已有 `~/.ssh/config` 或继承通配代理设置。将该命令交给同一台服务器上的 AI；命令不包含密码或私钥。

## 实现边界

- 使用现有 SSH.NET 通道反向转发，无需额外 FRP 服务。两端均绑定 `127.0.0.1`，各自自动分配高位空闲端口，不占本机或服务器既有 22 端口。服务器再次检查实际监听地址，拒绝公网绑定。
- 随完整测试包附带 Microsoft PowerShell/Win32-OpenSSH 10.4.0.0p1-Preview 的官方原始 ZIP，校验固定 SHA256 `b67ff8becd203502190ec42ac7787c24c2cd3325ed7700485fe7a1c83d2a7957`；管理员部署再验证 sshd、sshd-auth、sshd-session、ssh-keygen 的 Microsoft Authenticode 签名。该包上游发布名称含 Preview，未伪称 Windows 正式系统组件。
- 未调用会覆盖现有 sshd / ssh-agent 服务的上游 install-sshd.ps1，未添加防火墙规则，也未更改全局执行策略或默认 shell。专用二进制、主机密钥、授权文件及日志位于管理员管理的 `%PROGRAMDATA%\SafeCodeHostBridge`；私钥、授权文件和日志只允许 SYSTEM / Administrators 访问。
- 专用 SYSTEM 任务 `SafeCode-HostBridge` 无开机触发器，仅在明确启用时运行。心跳文件由本次登录 SID 维护；停止心跳 30 秒后关闭 SSH。内核 job 设置 KILL_ON_JOB_CLOSE，守护进程即使被终止也会结束所管理的 SSH 子进程。任务定义及已校验程序保留供下一次显式部署使用，停用不等于卸载程序。
- 每次启用在服务器普通工作用户下创建新的专用 Ed25519 身份；私钥保持 0600，不传回本机，不通过诊断或复制命令发送。固定本机 SSH 主机密钥，禁用密码认证、代理转发和 SSH TCP 转发。停用立即关闭反向通道，再尽力清理服务器专用密钥；服务器断线时不会承诺远端文件已清理。
- 启用时托盘显示“本机控制开”或连接异常状态，图标提示同步标记权限已启用。更新代码保留紧凑托盘、大文件传输、新建空白文件夹、目录挂载守护及 CloudCLI 项目联动。新版不自动启用本机控制。

## 验证状态

普通用户远端 helper 的真实回环 SSH、公钥验证、主机指纹拒绝、专用配置、不改用户全局 SSH 配置、移除密钥、参数及目录边界已测试。界面测试覆盖默认未授权、阻止未经勾选部署、忙碌防重复与关闭、成功命令展示和停用清除。挂载保存和空目录选择界面回归通过，CloudCLI / 目录边界回归也单独执行。

214 上仅做不开放访问的预检：PowerShell 模块按 UTF-8 文本解析，内核 job 实现编译并用独立 ping 子进程验证随 handle 关闭而结束；官方四个程序 Microsoft 签名有效，原生 `sshd -T` 对实际配置模板确认回环绑定、公钥认证、禁用密码及转发。预检没有启动本机控制 SSH 监听或创建 SYSTEM 控制任务。随后获得用户明确授权，通过真实界面临时启用并完成管理员部署、服务器工作用户到 214 的真实 SSH 登录、独立临时文件写入/读取/清理验证。实测登录令牌具有管理员权限。验收后点击停用，服务器反向监听、别名与专用私钥均已移除；本机监听、授权文件及运行中的 SYSTEM 任务均已停止，停止回执 nonce 匹配。原 1 组目录挂载已按保存映射恢复，本机控制最终保持关闭。

完整本机控制包在 214 桌面 `SafeCode-本机控制测试版-20261115`，常用 Safe Code 快捷方式已指向该目录；516 个文件逐项核对。当前 SSH 默认终端原为 Git Bash，本功能保留其注册表设置；验收使用显式 PowerShell 编码命令并处理原有终端编码。未读取用户业务文件，未向模型发起请求。
