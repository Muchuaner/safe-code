# Safe Code 0.4.1 · Windows 本地开发版

推荐运行 `SafeCode-0.4.1-Setup-x64.exe`，安装到当前用户的应用目录，桌面生成 Safe Code 快捷方式。无需管理员权限。安装包内含自包含 .NET 和微软 WebView2 完整离线安装程序；已经安装 WebView2 时直接复用。安装过程不下载这两项依赖。安装后的 DLL 与界面资源保存在应用目录，用户无需管理。

支持 Windows 10 2004（19041）及以后版本、Windows 11 x64；本版在 Windows 10 19045 验证。无需在电脑上安装 Python、Node.js、WSL 或 .NET SDK。SSH 终端调用 Windows 自带 OpenSSH Client；精简系统若没有此可选功能，需要启用。VPS 上的 Ubuntu 软件、Chrome、Claude Code 与 CloudCLI 由 VPS 自己联网下载，不消耗用户电脑的软件下载流量；远程桌面和文件传输仍使用用户网络。首次取得安装包需要下载完整 EXE，之后可离线复制安装。

## 使用

1. 阅读声明，输入 VPS 地址、管理员用户名和密码。默认 SSH 端口 22，可在“高级连接”修改。首次连接会要求核对 SSH 指纹；指纹变化会先询问是否重装过系统；确认并核对新指纹后，仅重新信任当前服务器。没有重装请选择“否”。
2. 软件先验证操作系统。非 Ubuntu 会警告并停止，不写部署文件。安装需要 root 或免密 sudo 账户。目标环境为完整 systemd 的 Ubuntu 22.04 / 24.04 x86_64，实际部署验证为 Ubuntu 24.04。
3. 建议 4GB 内存和至少 8GB 可用磁盘。第一步“自定义”可设置用户名、密码与机器名称。更换用户名会新建独立账户，保留旧账户和项目，并停止旧账户的 CloudCLI；需先在旧桌面中注销，并卸载已有目录。先创建工作用户，再部署所需组件。可单项执行，或勾选后批量执行；真实状态已完成的项不可重复勾选。
4. 本土化按出口 IP 的多源定位给出建议，也可手动确认。日本为 Asia/Tokyo + ja_JP.UTF-8。系统语言会安装相应翻译包，与中文输入法分别配置。
5. 维护模式可查看 / 复制软件创建的工作账户、打开远程桌面、打开真实 SSH 终端。账户不是管理员账户，密码可在第一步“自定义”设置，留空时独立随机生成。终端调用 Windows 自带 OpenSSH；若系统精简镜像没有 SSH 客户端，请先启用 Windows 的 OpenSSH Client 可选功能。
6. CloudCLI 安装后通过本机 SSH 隧道在浏览器打开。首次使用需创建其网页账户，并由本人完成 Claude 账号授权。程序不代登录 Claude，不包含订阅或 API 配额。

安装在 VPS 上以独立后台任务运行，断开客户端不会强行终止 apt。重新连接会恢复运行中任务的监控；发生错误后依据实际状态重试。关闭窗口会释放本应用的隧道、终端 SSH 连接与远程桌面连接，远端 tmux / 桌面会话按服务端配置保留。

## 目录挂载

先安装组件，打开“设置”，本地选择从“文档”开始；服务器选择从工作用户的 `~/workspace` 开始，两者均可向上浏览。选择或填写工作用户主目录下的服务器路径，支持多组。文件经独立会话认证的回环 WebDAV 与反向 SSH 通道传输，不开放本机公网文件服务。服务器实际挂载点由 root 管理，并在所选用户路径建立入口，避免普通用户替换挂载路径影响系统文件。

使用挂载中的文件时需保持 Safe Code 运行。正常退出会同步并卸载；若目录仍在使用，软件会保留窗口，要求先关闭远端正在使用的文件。请勿强行结束进程或在传输中关闭电脑。此版使用 davfs2 缓存，VPS 需保留缓存空间；单文件传输上限为 2GB，建议用于代码项目。避免两端同时覆盖同一文件。

设置在本机按服务器 SSH 指纹分别保存，不会自动挂载；重新连接后请确认并应用。账号密码、代码文件不会发送给开发者。

## 出入口 IP

仅配置服务商已分配并绑定在同一网卡上的 IPv4，要求单默认路由；不负责购买、分配或凭空添加 IP。入口负责管理接入，出口负责主动对外访问。修改前后都会新建 SSH 连接核对同一主机密钥，并检查实际出口；未通过时回退。另设 120 秒独立回退保护，不依赖客户端在线。规则只管理本软件的 nft 表与首选源路由，不清空用户其他防火墙规则。

启用固定出口后，指定出口不可用时不回退到其他 IPv4，也阻止非回复方向的公网 IPv6。管理入口的回复流量保留，避免破坏 SSH 返回路径。更换 IP 前先卸载本地目录。

## 数据与限制

- 成功连接后，IP、端口、登录用户名及密码整体通过 Windows DPAPI CurrentUser 加密保存在 `%LOCALAPPDATA%\SafeCode\login.dpapi`，下次自动填写；不会以明文保存密码或上传。删除此文件可清除已保存的登录信息。
- 工作账户密码保存在 VPS 的 root 专属状态目录，供管理员恢复查看；外部手动改密码后，原记录不会自动得到新密码。
- SSH 私钥保存在当前 Windows 用户的 LocalAppData 下，限制为本人访问；首次指纹信任记录保存在同一目录。
- 远程桌面仅监听服务器回环地址。通过已核对主机密钥的 SSH 隧道访问，由 Windows 自带的微软远程桌面组件打开独立窗口，账户密码经内存接口直接传递以自动登录 xrdp，不写入 RDP 文件或命令行。
- 延迟和丢包为每 5 秒一次 ICMP 探测，丢包率统计最近 20 次；“未响应”不代表 SSH 不通。
- 识别实际出口会访问 ipify；IP 定位与评分将出口 IP 发给 Net.Coffee，不发送账户、密码或文件。多源数据冲突时采用多数定位；不能确定的地区要求手动选取。评分仅作第三方参考。

这是本地开发版，未上传此版本到 GitHub。完整源码、构建方式与测试范围见项目 README 和 docs。

## 更新、反馈与统计

声明页的基础使用统计默认勾选，点击确认后开始上报；取消勾选停止并记住选择。统计仅含随机安装编号、启动次数、软件版本及 Windows 类型。接收方为 `safecode.tommukan.dpdns.org` 的洛杉矶服务；不包含 VPS 地址、账号、密码或文件。可在窗口底部“更新与反馈”随时关闭统计并主动填写反馈，反馈不附带日志。

客户端自动检查 GitHub 最新正式 Release，也可手动检查。发现新版后，下载并验证 SHA256，点击安装时先同步目录、关闭当前客户端，再运行安装向导。GitHub 尚未发布正式 Release 时会明确提示，更新检查失败不影响正常使用。完整离线安装包仍可手动复制安装。

首次确认使用声明后，本机当前用户下次直接进入登录页，旧版已有确认记录也会迁移。点击连接会立即进入主界面，连接、系统检查和评分进度在里面显示，完成前不能操作部署项。连接失败使用居中可关闭的中文提示，可在主界面重试或返回修改登录信息；高级连接使用同风格的端口设置窗口。
