# Safe Code Beta-0.4.3.3 · Windows 测试版

推荐运行 `SafeCode-Beta-0.4.3.3-Setup-x64.exe`，安装到当前用户的应用目录，桌面生成 Safe Code 快捷方式。无需管理员权限。安装包内含自包含 .NET 和微软 WebView2 完整离线安装程序；已经安装 WebView2 时直接复用。安装过程不下载这两项依赖。安装后的 DLL 与界面资源保存在应用目录，用户无需管理。

支持 Windows 10 2004（19041）及以后版本、Windows 11 x64；本版在 Windows 10 19045 验证。无需在电脑上安装 Python、Node.js、WSL 或 .NET SDK。SSH 终端调用 Windows 自带 OpenSSH Client；精简系统若没有此可选功能，需要启用。VPS 上的 Ubuntu 软件、Chrome 与 CloudCLI 由 VPS 自己联网下载；完整测试包附带 Linux x64 的官方 Claude Code 文件，安装时校验 SHA256 并通过 SSH 上传；未附带匹配架构文件的包由客户端从官方发布服务下载并缓存，会使用本机下载流量；远程桌面和文件传输仍使用用户网络。首次取得安装包需要下载完整 EXE，之后可离线复制安装。

## 使用

1. 阅读声明，输入 VPS 地址、管理员用户名和密码。默认 SSH 端口 22，可在“高级连接”修改。首次连接会要求核对 SSH 指纹；指纹变化会先询问是否重装过系统；确认并核对新指纹后，仅重新信任当前服务器。没有重装请选择“否”。
2. 软件先验证操作系统。非 Ubuntu 会警告并停止，不写部署文件。安装需要 root 或免密 sudo 账户。目标环境为完整 systemd 的 Ubuntu 22.04 / 24.04 x86_64，实际部署验证为 Ubuntu 24.04。
3. 建议 4GB 内存和至少 8GB 可用磁盘。第一步“自定义”可设置用户名、密码与机器名称。更换用户名会新建独立账户，保留旧账户和项目，并停止旧账户的 CloudCLI；需先在旧桌面中注销，并卸载已有目录。先创建工作用户，再部署所需组件。可单项执行，或勾选后批量执行；真实状态已完成的项不可重复勾选。
4. 本土化按出口 IP 的多源定位给出建议，也可手动确认。日本为 Asia/Tokyo + ja_JP.UTF-8。系统语言会安装相应翻译包，与中文输入法分别配置。
5. 维护模式可查看 / 复制软件创建的工作账户、打开远程桌面、打开真实 SSH 终端。账户不是管理员账户，密码可在第一步“自定义”设置，留空时独立随机生成。终端调用 Windows 自带 OpenSSH；若系统精简镜像没有 SSH 客户端，请先启用 Windows 的 OpenSSH Client 可选功能。
6. CloudCLI 安装后通过本机 SSH 隧道在浏览器打开。首次使用由用户自己设置网页账号和密码；安装器会补齐 Git 配置并跳过 Git Configuration、Connect Agents 两页，创建账号后直接进入主界面，需要使用模型时再由本人登录 Claude Code。已有 Git 姓名和邮箱保留；未配置时使用工作用户名和本地占位邮箱，可在设置中修改为本人 Git 身份。程序不代登录 Claude，不包含订阅或 API 配额。

安装在 VPS 上以独立后台任务运行，断开客户端不会强行终止 apt。重新连接会恢复运行中任务的监控；发生错误后依据实际状态重试。关闭窗口会释放本应用的隧道、终端 SSH 连接与远程桌面连接，远端 tmux / 桌面会话按服务端配置保留。

维护模式提供“云桌面自适应缩放”开关，开启后远端分辨率保持所选值，画面随远程桌面窗口等比例放大或缩小。设置会记住，默认关闭；分辨率仍可通过原有按钮主动修改。实现说明及验证步骤见 [固定分辨率缩放](RDP_SCALING.md)。

## 目录挂载

先安装组件，打开“设置”，本地选择从“文档”开始；服务器选择从工作用户的 `~/workspace` 开始，两者均可向上浏览。服务器目录选择器提供“新建空白文件夹”，输入名称后会创建并自动选中；同名目录不会被覆盖。选择或填写工作用户主目录下的新路径或空目录，支持多组；已有文件的目录不会被覆盖。文件经独立会话认证的回环 WebDAV 与反向 SSH 通道传输，不开放本机公网文件服务。服务器实际挂载点由 root 管理，并在所选用户路径建立入口，避免普通用户替换挂载路径影响系统文件。

使用挂载中的文件时需保持 Safe Code 运行。最小化后进入右下角托盘；有挂载时关闭主窗口也会转入托盘继续守护。点击托盘图标可查看挂载目录数、持续时长、双向流量和完成文件读写次数，并恢复主界面。从托盘“退出并安全卸载”退出会先等待远端同步并卸载；若连接未恢复或目录仍在使用，会保留保护并提示重试。强行结束进程或关机不属于持续守护范围。此版使用 davfs2 缓存，VPS 需保留缓存空间；已移除原先 2 GB 的单文件限制，采用流式传输和范围读取；大文件仍需要 VPS 有足够的整文件缓存空间。避免两端同时覆盖同一文件。

设置在本机按服务器 SSH 指纹分别保存，不会自动挂载；重新连接后请确认并应用。账号密码、代码文件不会发送给开发者。

## 出入口 IP

仅配置服务商已分配并绑定在同一网卡上的 IPv4，要求单默认路由；不负责购买、分配或凭空添加 IP。入口负责管理接入，出口负责主动对外访问。修改前后都会新建 SSH 连接核对同一主机密钥，并检查实际出口；未通过时回退。另设 120 秒独立回退保护，不依赖客户端在线。规则只管理本软件的 nft 表与首选源路由，不清空用户其他防火墙规则。

启用固定出口后，指定出口不可用时不回退到其他 IPv4，也阻止非回复方向的公网 IPv6。管理入口的回复流量保留，避免破坏 SSH 返回路径。更换 IP 前先卸载本地目录。

## 数据与限制

- 成功连接后，IP、端口、登录用户名及密码整体通过 Windows DPAPI CurrentUser 加密保存在 `%LOCALAPPDATA%\SafeCode\login.dpapi`，下次自动填写；不会以明文保存密码或上传。删除此文件可清除已保存的登录信息。
- 工作账户密码保存在 VPS 的 root 专属状态目录，供管理员恢复查看；外部手动改密码后，原记录不会自动得到新密码。
- SSH 私钥保存在当前 Windows 用户的 LocalAppData 下，限制为本人访问；首次指纹信任记录保存在同一目录。
- 远程桌面仅监听服务器回环地址。通过已核对主机密钥的 SSH 隧道访问，由 Windows 自带的微软远程桌面组件打开独立窗口，账户密码经内存接口直接传递以自动登录 xrdp，不写入 RDP 文件或命令行。
- 延迟和丢包为每 5 秒一次 ICMP 探测，丢包率统计最近 20 次；“未响应”不代表 SSH 不通。
- 识别实际出口会访问 ipify；IP 定位与评分将出口 IP 发给 Net.Coffee，不发送账户、密码或文件。多源数据冲突时采用多数定位；不能确定的地区要求手动选取。评分仅作第三方参考。

这是 Beta 测试版，通过 GitHub 预发布渠道分发。完整源码、构建方式与测试范围见项目 README 和 docs。

## 更新、反馈与统计

声明页的基础使用统计默认勾选，点击确认后开始上报；取消勾选停止并记住选择。统计仅含随机安装编号、启动次数、软件版本及 Windows 类型。接收方为 `safecode.tommukan.dpdns.org` 的洛杉矶服务；不包含 VPS 地址、账号、密码或文件。可在窗口底部“更新与反馈”随时关闭统计并主动填写反馈，反馈不附带日志。

客户端按版本通道检查 GitHub Release，也可手动检查。发现新版后，下载并验证 SHA256，点击安装时先同步目录、关闭当前客户端，再运行安装向导。GitHub 尚未发布正式 Release 时会明确提示，更新检查失败不影响正常使用。完整离线安装包仍可手动复制安装。

首次确认使用声明后，本机当前用户下次直接进入登录页，旧版已有确认记录也会迁移。点击连接会立即进入主界面，连接、系统检查和评分进度在里面显示，完成前不能操作部署项。连接失败使用居中可关闭的中文提示，可在主界面重试或返回修改登录信息；高级连接使用同风格的端口设置窗口。

## 参数保存与进阶安装

工作用户和机器名称的“自定义”仅保存本机参数，密码通过 Windows DPAPI 加密。保存不会修改服务器；点击该步骤“开始部署”才应用，已经完成的步骤在保存新参数后显示“更新”。失败时保留待应用参数以便重试，服务器身份变化后不会自动套用旧参数。

远程桌面卡片提供分辨率设置：1024×768、1280×800（默认）、1366×768、1600×900、1920×1080。保存在当前 Windows 用户下，窗口大小跟随所选分辨率调整，超出本机工作区时按比例缩小。已打开的窗口也会调整；服务器支持时同步更新远程像素分辨率，否则下次连接生效。

目录挂载与 CloudCLI 的安装会立即打开实际进度日志，关闭日志窗口不停止安装，卡片仍显示最新日志并可重新展开。目录浏览独立于安装队列，等待时显示进度，超时可重试；仅以普通工作用户列目录，不增加目录权限。

Beta 版检查本仓库预发布和正式 Release；正式版仅检查正式 Release。同版本正式版优先于 Beta，同一 Beta 按最后的测试修订号比较。

保存挂载设置时，按钮显示“正在挂载…”，窗口展示转圈、实际操作进度及等待时间，并阻止重复提交。失败后保留填写内容，可修改后重试；多行错误会完整显示。重新应用前先检查服务器目标目录，检查未通过会保留原文件通道和已保存设置。


出入口 IP 保存时会核对本机已分配地址，显示实际步骤及用时，验证期间禁止重复提交和关闭设置弹窗。变更由服务器独立执行，通过全新 SSH 连接核对身份与实际出口；失败有自动回退，页面保留填写内容便于修正。取消“固定住宅出口”表示恢复首次设置前的默认首选源，不保证继续使用填写的住宅地址；顶部始终显示外部实际检测结果。变更成功后新入口会保存到本机加密连接记忆。网络异常后按提示重新连接原入口核对状态。

出入口 IP 控件仅能选择服务器检测到的已绑定公网 IPv4，不提供手动输入或粘贴入口；没有检测到有效地址时禁用保存。选择菜单支持键盘方向键、Enter 与 Escape，显示当前选中地址。服务端仍在保存时重新核对 IP 归属，防止过期检测结果被应用。

## Claude 防封与避坑指南

为降低 Anthropic 账号风控与封禁概率，结合社区实测经验，建议严格遵循以下四项原则：

1. **坚决不碰成品号、代充与成品邮箱**：
   - 所谓“成品号”绝大多数由脚本批量利用脏代理或虚拟接码平台注册，初始即在 Anthropic 风控灰名单中。
   - “代充”绝大多数采用被盗黑卡或易拒付的低质虚拟卡，极易引发风控退单并永久封禁账号，且连带封禁对应设备指纹与出口 IP。
   - **正确做法**：必须使用自己能完全掌控的常用个人邮箱（优先自注 Gmail 或 Outlook），使用真实手机号完成验证，注册登录全程由本人操作。

2. **优先走苹果 App Store / 谷歌官方内购**：
   - 苹果（iOS）与谷歌（Google Play）内购依托成熟的应用商店支付体系，风控通过率最高、极少发生连带封号，且遇到扣费异常时官方客服退款成功率最高。
   - **正确做法**：手机登录美区或支持地区的 Apple ID / Google 账号，在官方 App 内订阅 Pro 套餐，之后在 VPS 或网页版中使用同一账号同步权益。
   - 若直接绑定国际信用卡，账单地址、卡归属国需与当前网络出口逻辑自洽，切勿频繁更换不同国家的支付卡。

3. **阶梯养号：由浅入深，切忌新号秒充**：
   - 新账号刚注册直接秒充 Pro / Max，极易触发自动化注册欺诈拦截（秒充即秒封）。
   - **正确节奏**：新账号在同一稳定网络环境下，先使用 1~3 天 Free 基础问答与日常轻量交互，让风控系统建立正常人类使用画像后再行升级。
   - 日常使用避免极端高并发请求、非正常密集循环调用以及跨时区无规律突发大流量。

4. **环境与网络出口绝对一致**：
   - 注册、登录、升级、网页 CloudCLI 和终端 Claude Code 尽量固定在同一出口（如 Safe Code 管理的固定住宅/VPS 出口）。
   - 切忌在电脑/手机直连网络与海外节点之间频繁秒切，避免触发地理位置瞬移风控。Safe Code 的出入口锁定可防止网络意外回退至直连。

## Beta-0.4.3.4：安装准备与 Claude Code 下载改进

首个安装任务先等待 APT/dpkg 更新结束（最多 15 分钟，持续显示等待日志），随后更新软件源并升级当前 Ubuntu 版本的软件包，成功后才继续安装组件。失败不记录为准备完成，重试会继续检查。不会删除包管理器锁文件、停止系统自动更新、跨 Ubuntu 大版本升级或自动重启。系统提示需要重启时只显示提醒。已完成的准备会跳过，单纯修改既有工作账户不会触发系统升级。

Claude Code 不需要目标服务器解析 `claude.ai` 来下载安装。客户端从 `downloads.claude.ai` 获取官方稳定版及 SHA256 清单，校验下载文件后通过已核对主机密钥的 SSH 上传；服务器再次校验，并以普通工作用户安装未修改的程序。后台任务独立保存安装文件，断线后可以继续监控。本次完整测试包内置官方 Claude Code 2.1.311 的 Linux x64 文件，优先在本地校验后上传，不需要本机或服务器临时下载 Claude Code；其他未附带匹配架构文件的构建会从官方服务获取稳定版并缓存，首次获取需要本机联网。未另行验证清单的 GPG 签名。

DNS 失败提示具体域名与中文原因；HTTP 拒绝、下载超时和系统包更新占用分开说明，不统称为“没有网络”。这只解决下载安装路径，Claude Code 后续登录、自动更新和模型访问仍取决于服务器到官方服务的网络；程序不会代替用户登录或更换服务器 DNS。

## Beta-0.4.3.4：挂载守护

挂载使用独立 SSH 连接，短暂断线后自动核对原主机指纹，恢复原远端端口与文件桥会话。活跃 FUSE 挂载及待上传缓存保留，不以全量卸载重挂的方式恢复网络。若服务器挂载本身丢失，则只恢复缺失项；正常目录保持原挂载。主控制连接断开时也会重建控制通道。服务器身份变化时停止自动连接，提示人工核对，不自动信任新密钥。

传输统计仅在本地显示，不扫描全部目录计算文件数，不上传文件或路径。“发送到服务器”和“接收到本机”为实际文件内容字节，重试和中断前已传输的字节会计入；“完成文件读写次数”统计完整 GET / PUT 成功次数，重复读写重复计数，目录扫描和部分范围读取不计入。守护时长包含暂时断线时间。仅关闭或最小化窗口不会停止守护，退出客户端需要安全卸载。

davfs2 会在 VPS 本地缓存打开的完整文件，因此虚拟机仍需留出足够缓存空间；已改进超时与重试，网络故障时保留缓存，安装器不会删除用户未上传的缓存文件。服务端最大单次上传保护上限为 1 TiB，实际容量受 VPS 及本机磁盘限制。

## 开发中：挂载与 CloudCLI 项目联动（2026-11-15）

挂载成功后自动将每组目录登记为 CloudCLI 项目，名称使用所选服务器文件夹名称。网页打开时约 3 秒内自动刷新项目列表，不刷新整页。首次使用此测试版时，请从 Safe Code 重新打开一次 CloudCLI，或刷新已有网页，以加载联动组件。先挂载后安装 CloudCLI，以及已有挂载后再打开网页，均会补登记。

自动登记使用实际挂载路径，避免 Claude 会话产生重复项目；新路径按目录固定，多组改序保持项目身份。主动卸载后，Safe Code 创建的项目归档，历史会话保留，重新挂载同一目录后恢复。用户自行添加的项目、改过的项目名称和收藏不覆盖。短暂断线保持项目，恢复挂载不会重复添加。CloudCLI 项目登记失败会单独提示，挂载文件通道保持运行，可重新打开 CloudCLI 重试。

## 开发中：本机远程控制（2026-11-15）

## Beta-0.4.3.5：登录信息与改密恢复

登录页提供“这些信息在哪？”教程，用示例 IP 演示如何在 VPS 控制台查找服务器登录信息。服务器登录密码、服务商网站密码、Safe Code 工作用户密码分别使用，不应混用。调整输入框间距和等宽辅助按钮，兼顾默认窗口与较矮窗口。

若在 VPS 控制台或 SSH 内修改了 root 等登录账户密码，已有 SSH 会话可能继续存活，但新 SSH/SFTP 连接仍会使用客户端原先记住的密码而失败。请点击主界面服务器卡片的“更新登录密码”，输入该登录账户的新密码。验证同一服务器身份、新密码和恢复通道后更新本机加密记忆，并恢复原挂载。错误密码或准备失败不会关闭原文件桥；认证失败暂停自动重试，普通网络故障仍重试。远程桌面或网页通道若已断开，请重新打开。此入口不修改服务器密码，也不能绕过服务器认证策略。

工作账户首次保存只记录草稿；第二次起，或服务器已有完成的工作账户时，保存会显示修改提醒。选择“我不改了”不保存本次更改；选择“我知道自己在做什么，更改并应用”保存并立即应用。账户配置说明明确工作密码不会修改 root 密码。
