# Safe Code 0.2 · Windows 本地开发版

解压整个文件夹，双击 `SafeCode.exe`。不要只复制 exe，旁边的 DLL 和 Web 文件夹必须保留。

支持目标为 Windows 10 / 11 x64；本版已在 Windows 10 19045 实测。不需要在电脑上安装 .NET、Python、Node.js 或 WSL。需要 Microsoft Edge WebView2 Runtime；通常已随 Windows / Edge 安装。若提示缺少，可从微软官方下载：https://developer.microsoft.com/microsoft-edge/webview2/

## 使用

1. 阅读声明，输入 VPS 地址、管理员用户名和密码。默认 SSH 端口 22，可在“高级连接”修改。首次连接会要求核对 SSH 指纹；指纹变化会拒绝连接。
2. 软件先验证操作系统。非 Ubuntu 会警告并停止，不写部署文件。安装需要 root 或免密 sudo 账户。目标环境为完整 systemd 的 Ubuntu 22.04 / 24.04 x86_64，实际部署验证为 Ubuntu 24.04。
3. 建议 4GB 内存和至少 8GB 可用磁盘。先创建工作用户，再部署所需组件。可单项执行，或勾选后批量执行；真实状态已完成的项不可重复勾选。
4. 本土化按出口 IP 的多源定位给出建议，也可手动确认。日本为 Asia/Tokyo + ja_JP.UTF-8。系统语言会安装相应翻译包，与中文输入法分别配置。
5. 维护模式可查看 / 复制软件创建的工作账户、打开远程桌面、打开真实 SSH 终端。账户不是管理员账户，密码为独立随机生成值。终端调用 Windows 自带 OpenSSH；若系统精简镜像没有 SSH 客户端，请先启用 Windows 的 OpenSSH Client 可选功能。
6. CloudCLI 安装后通过本机 SSH 隧道在浏览器打开。首次使用需创建其网页账户，并由本人完成 Claude 账号授权。程序不代登录 Claude，不包含订阅或 API 配额。

安装在 VPS 上以独立后台任务运行，断开客户端不会强行终止 apt。重新连接会恢复运行中任务的监控；发生错误后依据实际状态重试。关闭窗口会释放本应用的隧道、终端 SSH 连接与临时 RDP 凭据，远端 tmux / 桌面会话按服务端配置保留。

## 目录挂载

先安装组件，打开“设置”，选择本机目录并填写工作用户主目录下的服务器路径，支持多组。文件经独立会话认证的回环 WebDAV 与反向 SSH 通道传输，不开放本机公网文件服务。服务器实际挂载点由 root 管理，并在所选用户路径建立入口，避免普通用户替换挂载路径影响系统文件。

使用挂载中的文件时需保持 Safe Code 运行。正常退出会同步并卸载；若目录仍在使用，软件会保留窗口，要求先关闭远端正在使用的文件。请勿强行结束进程或在传输中关闭电脑。此版使用 davfs2 缓存，VPS 需保留缓存空间；单文件传输上限为 2GB，建议用于代码项目。避免两端同时覆盖同一文件。

设置在本机按服务器 SSH 指纹分别保存，不会自动挂载；重新连接后请确认并应用。账号密码、代码文件不会发送给开发者。

## 出入口 IP

仅配置服务商已分配并绑定在同一网卡上的 IPv4，要求单默认路由；不负责购买、分配或凭空添加 IP。入口负责管理接入，出口负责主动对外访问。修改前后都会新建 SSH 连接核对同一主机密钥，并检查实际出口；未通过时回退。另设 120 秒独立回退保护，不依赖客户端在线。规则只管理本软件的 nft 表与首选源路由，不清空用户其他防火墙规则。

启用固定出口后，指定出口不可用时不回退到其他 IPv4，也阻止非回复方向的公网 IPv6。管理入口的回复流量保留，避免破坏 SSH 返回路径。更换 IP 前先卸载本地目录。

## 数据与限制

- root 登录密码仅在本次客户端会话内使用，不写入配置或日志。
- 工作账户密码保存在 VPS 的 root 专属状态目录，供管理员恢复查看；外部手动改密码后，原记录不会自动得到新密码。
- SSH 私钥保存在当前 Windows 用户的 LocalAppData 下，限制为本人访问；首次指纹信任记录保存在同一目录。
- 远程桌面仅监听服务器回环地址。首次 MSTSC 连接可能需要本人确认服务器证书。
- 延迟和丢包为本机发出的 5 次 ICMP 探测；“未响应”不代表 SSH 不通。
- 识别实际出口会访问 ipify；IP 定位与评分将出口 IP 发给 Net.Coffee，不发送账户、密码或文件。多源数据冲突时采用多数定位；不能确定的地区要求手动选取。评分仅作第三方参考。
