# 匿名安装诊断（Beta-0.4.3.3）

用户可在“更新与反馈 → 故障诊断”开启“同意自动上传匿名安装诊断”。默认勾选，可随时取消；升级时缺少此字段的旧配置使用默认勾选，已经明确关闭的选择保持关闭。此开关独立于基础使用统计，仍需已确认声明。开启后，从下一次连接或安装操作开始收集；成功、失败及取消都会生成一份有界 JSON 诊断报告。声明确认前、验收模式及关闭状态不收集、不发送。关闭会立即取消在途请求，重新开启也不会补发之前的报告。

报告只含随机提交编号、软件版本、固定操作类型、成功/失败/取消、耗时、固定错误分类、固定代码位置、最多 64 个带相对秒数的步骤事件，以及被丢弃的未知日志行数。支持账户、本土化、桌面、Chrome、输入法、Claude、SSH、CloudCLI、挂载组件、目录挂载及这些任务的恢复监控。服务器记录接收时间。

原始日志不是报告的一部分：只将已知模式投影为固定词表，例如 `package_lock_wait`、`dns_failure`、`directory_not_found`、`account_draft_clear`。未识别的文本直接丢弃。这会牺牲部分排错细节，但避免依赖容易漏掉秘密的字符串替换。即使日志夹带密码、令牌、IP、邮箱、私钥、URL 或本地/远端路径，也不会将输入片段拼接进报告。报告没有安装编号、服务器标识、用户名、机器名、项目目录、原始异常、堆栈或文件内容，不读取历史日志目录。

每个进程最多尝试发送 20 份，最多同时发送 2 份；单份最多 12 秒，网络或 5xx 错误最多尝试 2 次，重试复用提交编号去重。无磁盘缓存、压缩包或离线积压，发送失败不会改变安装结果，也不会产生第二次报错。网络连接仍会让接收服务器与 Cloudflare 看见来源 IP，业务数据库不保存它。

服务端 POST `/v1/diagnostics` 严格校验每一层字段、枚举和数值范围，拒收额外文本。诊断保留 30 天，每次写入任一接口时清理过期项；共享现有 32KB 请求上限、数据库上限及代理全局限流，另按来源内存摘要限制为每小时 20 次。无公开查询接口，通过原有 SSH 运维读取：

```sh
python3 /opt/safe-code-feedback/report.py /var/lib/safe-code-feedback/data.sqlite3 --diagnostics
```

发布顺序：先备份并更新反馈服务的 `server.py`、`report.py`，重启该独立服务；再在专属 Nginx location 放行 `v1/diagnostics`，通过 `nginx -t` 后 reload；验证现有 usage/feedback/health 后再发布新客户端。升级仅新增 diagnostics 表，保留现有统计和反馈。2026-11-10 已完成线上接收端升级，HTTPS 验收和数据库回读通过；安装包随 Beta-0.4.3.3 发布。

本地验证：反馈服务单测；`tools/SafeCode.Services.Verify` 的诊断隐私、授权、取消、重启和界限检查；`tools/test_diagnostics_ui.py` 的独立开关、默认勾选和小窗口可访问性检查。Windows 原生客户端的真实上报仍需随发布验收，当前跨平台测试不等同于 Windows 实机验收。
