# 匿名功能诊断

在「更新与反馈」中可分别选择基础使用统计和匿名功能诊断。两个选项默认关闭。诊断从确认授权后的新操作开始采集，关闭时停止发送并取消在途请求。

报告包含软件版本、随机关联编号、固定操作和错误分类、结果、耗时及已知的步骤。覆盖服务器连接、部署、挂载、远程桌面、客户端接入和网关管理。报告不读取原始日志，也不上传密码、Key、服务器地址、本地路径、对话或请求正文。Safe Code API 的逐 Key 用量保存在网关所在服务器。

手动提交反馈独立于上述开关。开启匿名诊断时，反馈可同时附带最近一次失败的摘要和问题编号。反馈前请确认文本中没有账号密码、Key 或连接凭据。

匿名诊断保留 30 天，基础使用统计保留 90 天，手动反馈保留 180 天。接收端只开放上报接口，来源限流在内存中处理。网络传输仍会把来源 IP 暴露给接收端和网络代理，业务数据库不保存原始 IP。

接收端的运行和报表入口见 [反馈服务](../services/feedback/README.md)。
