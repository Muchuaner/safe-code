# 匿名功能診斷

在「更新與回饋」中可分別選擇基礎使用統計和匿名功能診斷。兩個選項預設關閉。診斷從確認授權後的新操作開始採集，關閉時停止傳送並取消在途請求。

報告包含軟件版本、隨機關聯編號、固定操作和錯誤分類、結果、耗時及已知的步驟。覆蓋伺服器連線、部署、掛載、遠端桌面、客戶端接入和網關管理。報告不讀取原始日誌，也不上載密碼、Key、伺服器地址、本地路徑、對話或請求正文。Safe Code API 的逐 Key 用量儲存在網關所在伺服器。開啟診斷後，Key 接入請求失敗的摘要還包含 VPS 網關階段、活動請求數、排隊和槽位、分段耗時、請求與響應位元組數以及各層 HTTP 狀態。Claude Code 或 CloudCLI 明確提供 Anthropic 錯誤類型或請求編號時也會記錄；欄位缺失代表上游未提供。

手動提交回饋獨立於上述開關。開啟匿名診斷時，回饋可同時附帶最近一次失敗的摘要和問題編號。回饋前請確認文本中沒有帳號密碼、Key 或連線憑據。

匿名診斷保留 30 天，基礎使用統計保留 90 天，手動回饋保留 180 天。接收端只開放上報接口，來源限流在記憶體中處理。網絡傳輸仍會把來源 IP 暴露給接收端和網絡代理，業務資料庫不儲存原始 IP。

接收端的執行和報表入口見 [回饋服務](../services/feedback/README.md)。
