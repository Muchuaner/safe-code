# 目录挂载与 CloudCLI 项目联动

成功挂载后，每组目录自动出现在 CloudCLI 原生项目列表中，名称使用服务器目录名。安装或打开 CloudCLI 时也会补登记现有挂载。当前对照安装器使用的 CloudCLI 1.37.7 项目表和网页刷新事件验证；未知数据结构会停止登记并单独提示，保留已成功的挂载通道。

项目使用实际挂载路径，与 Claude 的工作路径一致。新路径按目录稳定生成；旧版 m0/m1 路径及其目录对应关系在首次成功应用时持久保存，卸载后重新挂载、多组改序仍保留项目身份。重连继续沿用现有记录，不访问可能失联的 FUSE 目录进行项目枚举。

只有 Safe Code 创建的项目受自动归档和恢复管理。主动卸载后项目归档，历史会话保留；重新挂载后恢复原 ID。手工创建的项目及其归档状态不接管，项目名称、收藏和用户凭据不覆盖。项目操作以普通工作用户执行，通过 SQLite 事务完成，不运行 Claude、不发起模型请求。

网页加载一个小型联动组件，每 3 秒读取仅含随机修订号的静态文件，变化时触发 CloudCLI 原有刷新事件，不重载整页，也不操作终端 socket。隐藏网页暂停轮询，重新显示时补刷新。首次升级需要重新打开或刷新已有 CloudCLI 网页一次；后续挂载自动联动。更新 CloudCLI 覆盖网页资源后，再从 Safe Code 打开或应用挂载会重新安装组件；原网页入口有备份，服务无需重启。
