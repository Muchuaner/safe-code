# 更新记录

以下功能纳入 Beta-0.4.3.4（2026-11-15）；历史开发记录的“尚未发布”描述以本条为准。Codex 接入 Claude 只交付默认关闭的实验组件，用户已选择不运行验收。

## 安装失败状态码 100 的说明（2026-11-11）

用户要求纳入下次更新；2026-11-14 已在开发代码中实现原因分类与状态码 100 提示，尚未发布客户端。

本土化、虚拟桌面等安装步骤遇到 APT 状态码 100 时，在状态码后补充：

> 可能是系统正在更新，请稍后重试；如果仍有问题，请提交反馈。

保留原状态码。状态码 100 也可能由软件包下载失败等原因引起，因此使用“可能”，不把所有失败都断言为系统更新。若已有明确原因，应优先展示具体原因，并保留稍后重试及提交反馈的指引。

## 安装准备与 Claude Code 下载（2026-11-15）

开发代码已增加：首个安装任务等待包管理器空闲、更新软件源与当前系统软件包，准备成功后继续；完整测试包附带官方未修改的 Claude Code Linux x64 文件，优先校验后上传；未附带匹配架构文件时由客户端从官方稳定发布源下载、缓存并校验后上传，目标服务器不再依赖解析 claude.ai 下载安装脚本；DNS 与下载失败以中文解释。尚未发布正式客户端，验证结果见 docs/INSTALLATION_2026-11-15.md。

## CloudCLI 首次设置精简（2026-11-15）

保留用户自行创建网页账号和密码。安装 CloudCLI 时补齐缺失的工作用户 Git 身份，并为现有及随后自行注册的网页账号完成 Git / Connect Agents 技术引导；直接进入主界面后再由用户按需授权 Claude Code。打开旧安装的 CloudCLI 时也会执行兼容初始化，不重装或重启服务。已有 Git 姓名、邮箱、账号密码和授权记录不覆盖。尚未发布正式客户端。

## 大文件、空目录和托盘守护（2026-11-15）

开发代码移除 2 GB 文件硬限制，增加流式范围读取、空闲超时与独立文件写入锁；服务器目录选择器新增空文件夹创建并自动选中。新增绿色托盘面板和底部状态入口，显示目录数、时长、双向字节和完成文件读写次数；独立挂载通道断线后保留原会话和缓存重连，服务器挂载缺失时仅恢复缺失项。退出前安全同步卸载，失败时继续保护。尚未发布正式客户端；验收记录见 docs/MOUNT_GUARD_2026-11-15.md。

## 挂载与 CloudCLI 项目联动（2026-11-15）

成功挂载后登记原生项目；打开或安装 CloudCLI 时补登记已有挂载。网页通过独立无凭据修订标记触发原生列表刷新，不刷新整页、不操作终端连接。新挂载的实际路径按目录稳定生成，改序保留项目身份；卸载归档自动项目并保留会话，重挂恢复；手工项目、名称和收藏保留。联动失败单独提示，不影响已经成功的挂载。尚未正式发布。

## 托盘紧凑排版（2026-11-15）

面板宽度 252 DIP，目录和时长并排，发送/接收/读写三列，主界面/重连/安全退出横排小按钮，详细数据移至悬停说明。214 实机验证并恢复原 1 组挂载，常用快捷方式已切换到完整紧凑托盘测试版；挂载守护、新建空目录、大文件和 CloudCLI 联动继续保留。见 docs/TRAY_COMPACT_2026-11-15.md。

## 本机远程控制（2026-11-15，开发测试版）

接续此前暂缓的 OpenSSH / 本机映射方案，新增独立设置与权限确认、官方随包 SSH、双回环反向通道、专用密钥和主机指纹、命令复制、停用及断线守护。没有自动启用或开公网端口；用户明确授权后，已在 214 完成管理员部署、实际 SSH 登录、受控临时文件读写与停用撤权验收，最终保持关闭。见 docs/HOST_CONTROL_2026-11-15.md。

## Codex 接入 Claude（第三方适配测试组件）

读取并审查用户迁移包后，新增 SSH 后的独立模块、第三方运行与数据处理确认、项目只读默认、受限 SSH 身份、隔离配置、接口健康检查、配置/本机密钥复制、停止撤权及本机任务取消、托盘运行标记与作者待填写致谢位。不自动切换 Codex/CC Switch，不根据附件型号目录伪称账户模型可用。具体原始校验、许可与验证边界见 docs/CODEX_CLAUDE_BRIDGE_2026-11-15.md。
