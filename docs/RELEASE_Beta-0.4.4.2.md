# Safe Code Beta-0.4.4.2

本次同步更新 Windows 与 macOS，通过 GitHub 预发布渠道分发。

- Claude Code 默认由 VPS 从官方发布服务下载，按 VPS 架构选择文件并校验 SHA256；VPS 下载网络、DNS 或超时失败时再尝试客户端备用网络。新版发行包不内置 Claude 文件，避免每次先经本机上传大型安装文件；保留旧随包文件的校验兼容能力。
- 修复服务器新增主机密钥类型后，后续 SFTP、挂载及本机控制通道误选另一把密钥而被拒绝的问题。继续使用已确认的公钥类型并逐字节校验，真正替换密钥时仍拒绝连接，不会自动接受新指纹。校验失败提示改为中文。
- 调整工作账户设置顺序，在修改密码前先应用机器名称；若密码已更新但账户记录保存失败，明确提示密码已生效和恢复方式，避免误以为旧密码仍有效。工作用户密码与服务器登录账户密码分别管理。
- 两端均保留“更新登录密码”恢复入口：服务器改密后验证新凭据，保留原文件桥、挂载身份和待上传缓存；不通过强行关闭文件桥跳过同步保护。

Windows 10 2004 / Windows 11 x64：推荐 `SafeCode-Beta-0.4.4.2-Setup-x64.exe`，包含 .NET 和 WebView2 离线依赖；`win-x64.zip` 为便携包。继续保留 Microsoft OpenSSH、可选第三方适配器及原许可。

macOS 15 或更新系统：Apple Silicon 下载 `macOS-arm64.dmg`，Intel 下载 `macOS-x64.dmg`。Mac 包使用临时本机签名，未完成 Apple 公证；系统可能要求通过“隐私与安全性”手动允许打开。Intel 版本通过 Rosetta 启动检查，不等同于 Intel 硬件实机验收。Mac 不包含可运行的第三方模型适配器。

验证覆盖真实 SSH/SFTP 握手中的新增密钥类型、替换密钥零认证、VPS 优先下载、密码更新恢复、错误密码及恢复准备失败保护；以及官方文件校验、ARM64 架构选择、半成品清理、账户部分成功提示、界面和更新筛选回归。未修改用户 VPS，未运行第三方适配器或发送模型请求。

如果服务器本身无法访问官方下载服务，仍可能触发本机备用下载；本机与 VPS 均不可达时会停止并提示失败。未知原因的挂载和软件包失败仍需根据现场错误进一步核查，不将重复诊断次数当作独立 bug 数或故障率。
