# Safe Code v0.4.3

面向 Windows 10 / 11 x64 的本地 VPS 开发环境配置工具，服务端目标为 Ubuntu 22.04 / 24.04 x86_64。

本版本修正远程桌面窗口大小随分辨率变化的行为，并提供屏幕工作区限制。默认 1280×800，另有 1024×768、1366×768、1600×900、1920×1080。保存后调整已打开的窗口；远程会话是否能即时改变像素分辨率取决于服务端支持。

此前版本的主要功能包括账户与机器名称参数保存 / 更新、本土化、虚拟桌面、Chrome、中文输入法、Claude Code、SSH 终端、目录挂载和 CloudCLI。连接与安装状态来自真实检查，长任务显示实际日志；账号密码保存在本机当前用户的加密配置中。基础统计可关闭，反馈只在主动提交时发送。

安装文件：`SafeCode-0.4.3-Setup-x64.exe`，包含 .NET 与 WebView2 离线运行环境。更新流程仅使用本仓库正式 Release，下载需要资产 SHA256，安装前再次校验。

当前阶段：上线准备，尚未发布此版本。源码与安装包公开前需完成发布资产校验；首次正式 Release 后，再从旧版客户端做一次实际提示、下载、安装的生产闭环。当前不能把模拟资产测试当作已完成生产更新。

发布前检查已覆盖：源码不跟踪密码配置、私钥、证书私钥、反馈数据库、构建输出和本地验收资料；维护验收目标从本机测试配置显式授权，源码不内置个人 VPS 地址。GitHub 首发需同时提交说明、许可证和精确命名的安装资产，资产 digest 应能由公开 Release API 读取。
