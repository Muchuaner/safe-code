# Safe Code Beta-0.4.3.2

修复目录挂载保存等待时没有反馈、重复保存挂载失败，以及错误只显示 Traceback 第一行的问题。

点击“保存设置”后显示“正在挂载…”、转圈、服务器实际进度与用时，并阻止重复提交；失败后保留填写内容，修改后可重试。重新应用挂载时保留旧文件通道供服务端检查与同步，服务器目标目录检查未通过时保留原设置。非空目录会明确提示选择新的或空的服务器目录。

安装文件为 `SafeCode-Beta-0.4.3.2-Setup-x64.exe`，包含 .NET 和 WebView2 离线依赖。已安装 Beta-0.4.3.1 的用户可在“更新与反馈”中检查、下载并安装；普通正式版本不会收到 Beta 更新。

构建和本地回归测试通过，包含重挂载、无效目标保留旧通道、设置保存与清空、多行错误、界面等待状态与重试、WebDAV 文件读写与路径保护。Windows 到 Ubuntu 的实际挂载修复效果仍待用户复测。
