# Safe Code Beta-0.4.3.3

改进双 IP 设置、故障诊断和更新提示，并为桌面快捷方式增加两行文字图标。

- 出入口 IP 只能选择服务器检测到的已绑定地址；重做选择菜单，修复锁定勾选布局。保存时显示进度与用时，阻止重复提交；失败保留选择。
- 网络设置由服务器独立应用，用全新 SSH 连接核对身份和实际出口后保存；保留自动回退，清理过期且未应用的变更记录。新入口同步保存到本机加密连接记忆。
- 修复使用默认账户参数时，部署成功后清理不存在的草稿目录导致误报失败的问题。
- 基础使用统计与匿名安装诊断默认勾选，可分别关闭并记住选择。诊断仅含固定步骤、耗时与错误类型，不上传原始日志、凭据、地址、路径或文件内容；接收端已上线，诊断保留 30 天。
- 有更新时，Safe Code 标题右侧与底部同时显示醒目的可点击提示。
- 桌面快捷方式使用 SAFE / CODE 两行文字图标，未设置程序窗口图标。

Windows 客户端编译、隐私与授权检查、接收服务单测和 HTTPS 回读、界面回归均通过。214 上真实双 IP 切换与持久化自动验收通过，用户多次往返手动复测正常，借用 VPS 已恢复到保存的可用分流基线。测试使用 Google、Wikipedia 与出口检测，没有使用 Claude/Anthropic 网站。

下载 `SafeCode-Beta-0.4.3.3-Setup-x64.exe`，支持 Windows 10 2004（19041）及以上与 Windows 11 x64，含 .NET 与 WebView2 离线依赖。已安装 Beta 版可通过“更新与反馈”升级，正式版不接收 Beta 通道。
