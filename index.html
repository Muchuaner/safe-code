这些信息在哪？
打开 VPS 服务商控制台，找到你的服务器的“远程连接”或“登录信息”。将公网 IP、远程用户名和该账户当前的密码填入登录页。
这里需要服务器登录密码，不是服务商网站的账户密码，也不是 Safe Code 的工作用户密码。修改过 root 密码后，请使用新密码；部分控制台不会同步显示手动修改后的密码。


更新登录密码
在 VPS 控制台或 SSH 中修改了 root 等登录账户的密码？在这里验证新密码并恢复连接。此操作不会修改服务器密码，原挂载和待上传缓存会保留。
恢复后，如远程桌面或网页连接已断开，请重新打开。
